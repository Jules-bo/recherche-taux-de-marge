# Analyse du taux de marge des entreprises

## Présentation

Ce travail a été réalisé en juin 2026, alors que j'étais en classe de seconde, dans le cadre de mon stage d'observation à la Banque de France.

Il m'a été demandé par mon maître de stage d'étudier la question des taux de marge des entreprises. L'objectif était de comprendre leur définition, leur évolution et les différents mécanismes économiques susceptibles d'expliquer leurs variations.

Le travail aborde notamment :
- la définition et le calcul du taux de marge ;
- son évolution récente ;
- les différences entre secteurs ;
- les facteurs pouvant expliquer ses variations ;
- les liens entre taux de marge, prix, salaires, investissement et inflation ;
- les limites de cet indicateur.
